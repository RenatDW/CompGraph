## CompGraph

Десктопное приложение на Qt 6 для загрузки, преобразования и рендеринга 3D OBJ-моделей с собственным матричным и графическим конвейером. Включает управление моделями, камерами, растеризацию с Z-буфером, текстурирование, простое освещение и unit-тесты на GoogleTest.

### Возможности

- Загрузка и сохранение OBJ (сохранение исходной или преобразованной модели).
- Несколько моделей в сцене с выбором и трансформациями для каждой.
- Собственная математика (векторы, матрицы, аффинные преобразования).
- Растеризация с Z-буфером, каркас, текстуры и освещение.
- Редактирование модели: удаление треугольников/вершин в режиме удаления.
- Несколько камер с UI для добавления/выбора/удаления.
- Набор тестов GoogleTest для математики, рендера и OBJ-утилит.

### Управление и интерфейс

- Список моделей: выбор одной или нескольких; ПКМ для контекстного меню (редактировать/повернуть/удалить).
- Панель трансформаций: Rotate, Scale, Translate для выбранных моделей.
- Режимы рендера: Show mesh, Show texture, Show illumination.
- Цвет/текстура: выбор базового цвета или загрузка текстуры.
- Камера: ЛКМ и перетаскивание для вращения, колесо для зума.
- Режим удаления: переключение Normal/Delete; ЛКМ удаляет вершину или треугольник под курсором.

### Требования

- CMake 3.29+
- Компилятор C++20
- Qt 6.8 (Core/Gui/Widgets)
- OpenMP runtime (например, `libomp` на macOS)

### Сборка (macOS/Linux)

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.0/macos/lib/cmake
cmake --build build -j
```

### Сборка (Windows)

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:/Qt/6.8.0/mingw_64/lib/cmake
cmake --build build --config Release
```

### Запуск

```bash
./build/CompGraph
```

### Тесты

```bash
cmake --build build --target Google_Tests_run
./build/Google_tests/Google_Tests_run
```

### Структура проекта

- src/forms: UI на Qt, главное окно, обработка ввода.
- src/math: векторы, матрицы, depth/pixel buffers.
- src/model: структуры данных модели, полигоны/треугольники.
- src/obj_utils: OBJ reader/writer.
- src/render_engine: камера, растеризация, освещение, текстурирование.
- Google_tests: unit-тесты и зависимость GoogleTest.
- resources: Qt-ресурсы (иконки, stylesheet).

### Примечания и ограничения

- Путь к модели камеры сейчас захардкожен в [src/forms/mainwindow.cpp](src/forms/mainwindow.cpp#L321-L382), а OBJ-файла в репозитории нет. Обновите путь или добавьте локальный файл модели камеры.
- ObjReader бросает исключения, но диалоги ошибок в UI пока не подключены.
